brahma portable mode

While this file sits next to brahma.exe, brahma keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the BrahmaData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move brahma with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Brahma) instead.
If BrahmaData can't be written (for example on a read-only drive), brahma says so and
uses %APPDATA%\Brahma instead.
